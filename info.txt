n8n workflows बनाएं
आपका frontend सीधे Meta API को app secret नहीं भेजेगा। यह security के लिए गलत है। Frontend केवल आपके n8n webhook को call करेगा; n8n में Meta credentials सुरक्षित रहेंगे।

Workflow 1: Send WhatsApp Message
Frontend → n8n

POST https://your-n8n-domain/webhook/whatsapp-send

Request:

json
{
  "to": "919999999999",
  "message": "Hello Shivam, this is a test from Anvayra.",
  "clientRef": "demo-client"
}
n8n flow:

Webhook node

Validate input

HTTP Request node → Meta Graph API

Save response/log

Respond to Webhook

Meta Cloud API send-text endpoint का structure:

text
POST https://graph.facebook.com/v21.0/{PHONE_NUMBER_ID}/messages
Body:

json
{
  "messaging_product": "whatsapp",
  "recipient_type": "individual",
  "to": "919999999999",
  "type": "text",
  "text": {
    "body": "Hello Shivam, this is a test from Anvayra."
  }
}
Authorization header:

text
Authorization: Bearer {META_ACCESS_TOKEN}
Workflow 2: Create Message Template
Frontend → n8n

POST /webhook/whatsapp-template-create

Meta endpoint:

text
POST https://graph.facebook.com/v21.0/{WABA_ID}/message_templates
Body example:

json
{
  "name": "anvayra_demo_update",
  "language": "en",
  "category": "UTILITY",
  "components": [
    {
      "type": "BODY",
      "text": "Hello {{1}}, your Anvayra automation demo is ready."
    }
  ]
}
Workflow 3: List Templates
text
GET https://graph.facebook.com/v21.0/{WABA_ID}/message_templates
Workflow 4: Delete Template
text
DELETE https://graph.facebook.com/v21.0/{WABA_ID}/message_templates?hsm_id={TEMPLATE_ID}
